Part 2 — Make the plane fly

Written and checked on Godot 4.7. The older 4.4 wording still works on 4.7. If a sentence disagrees with the shipped project godot_tappy_plane/, trust the project files.

Last lesson you put a plane on screen. Now Space makes it climb, releasing Space lets it fall, and rocks enter from the right. At the end you will have a playable prototype.

Keep using the Part 1 practice project, or start from the 01-start zip. This lesson ends at 02-flight. Do not drag both projects into the same Godot project. Code blocks below are full files. Replace the matching path. The text around them explains why the lines exist.

Series: Tappy Plane course overview

1. Give the game a “flap up” action

Open Project → Project Settings → Input Map. Under Add New Action, type flap and add it. Expand it. Use the plus buttons to add Left Mouse Button and Physical Space. The action name’s case must match the code.

flap is the game action name. Code only cares that the player wants to go up. You do not write mouse and keyboard twice. To change keys later, edit the Input Map.

Then in Project Settings → Layer Names → 2D Physics, name layer 1 player and layer 2 rock. Names are for you. Detection uses the checkboxes on those layers.

2. Keep design numbers apart from live data

Gravity, flap strength, and rock speed are design numbers. Where the plane is going and what the score is are live data. A small Resource stores the first group so values are not copied into many scripts.

In FileSystem create src/config. Right-click, New Script, path src/config/game_config.gd, inherits Resource. Replace the template with:

class_name GameConfig
extends Resource

## Shared read-only config. Speed, score, and other live data live elsewhere.
@export var gravity: float = 400.0
@export var flap_power: float = 300.0
@export var flap_velocity_limit: float = 200.0
@export var min_tilt: float = -45.0
@export var max_tilt: float = 90.0
@export var rock_speed: float = 200.0
@export var spawn_interval: Vector2 = Vector2(1.0, 2.0)
@export var spawn_x: float = 632.0
@export var bottom_y: Vector2 = Vector2(216.0, 336.0)
@export var top_y: Vector2 = Vector2(-24.0, 112.0)
@export var despawn_x: float = -56.0
@export var plane_start: Vector2 = Vector2(72.0, 152.0)

First script in the course. You do not need every keyword memorized:

  • extends Resource — this script describes a saveable data resource.
  • class_name GameConfig — a type name other scripts and the editor can use.
  • @export — shows the field in the Inspector.
  • var gravity: float = 400.0 — a decimal named gravity, starting at 400.
  • Vector2(1.0, 2.0) here stores two numbers (interval min and max). It is not always a position.
  • ## is a doc comment. Comments do not run.

Save. Right-click src/config, New Resource, search GameConfig, save as default_game_config.tres. Keep the defaults. If GameConfig is missing from the list, check that the script saved and has no red parse errors.

The .tres can be shared by plane and rocks. Do not change it at runtime. Each plane keeps velocity on its own node. Each round keeps score on its own rules object. Shared config is not shared live state.

3. Animation and flap sound on the plane

Open plane.tscn. Change the Sprite2D to AnimatedSprite2D: right-click → Change Type. Keep the name Sprite2D. If old texture fields remain, confirm the type is AnimatedSprite2D.

In Sprite Frames, create a new SpriteFrames. Open the animation panel at the bottom. Add planeYellow1.png, planeYellow2.png, planeYellow3.png in number order to the default animation. Speed 5 FPS, loop on, autoplay on. Set this child’s Rotation to -45 degrees to match the original art facing.

Add an AudioStreamPlayer on Plane named AudioFlap. Stream: assets/audio/sound/coin1.ogg. Bus: SFX. If SFX is missing, in Project Settings set audio/buses/default_bus_layout to the imported assets/default_bus_layout.tres, then reopen the audio UI and confirm BGM and SFX exist.

Final plane tree:

Plane (CharacterBody2D, plane.gd)
├── Sprite2D (AnimatedSprite2D)
├── CollisionShape2D (CircleShape2D, radius 45)
└── AudioFlap (AudioStreamPlayer)

Root Scale stays (0.5, 0.5). Collision Layer: only player. Collision Mask: only rock. The node is still named Sprite2D; the type is AnimatedSprite2D. Keep those two facts separate when you read the tree.

4. Real flight logic

Select the Plane root. Attach src/entities/plane.gd. If Part 1 left an empty extends script, replace the whole file:

class_name TappyPlane
extends CharacterBody2D

@export var config: GameConfig
@onready var audio_flap: AudioStreamPlayer = $AudioFlap

#region Lifecycle
func _physics_process(delta: float) -> void:
	velocity.y += config.gravity * delta
	rotation_degrees = clampf(velocity.y / config.gravity * config.max_tilt,
		config.min_tilt, config.max_tilt)
	move_and_slide()

func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed("flap") and not event.is_echo():
		flap()
#endregion

#region Public
func flap() -> void:
	velocity.y = clampf(velocity.y - config.flap_power,
		-config.flap_velocity_limit, config.flap_velocity_limit)
	audio_flap.play()
#endregion

Save. Select Plane. Drag default_game_config.tres into the new Config slot. Skip this and config.gravity will error.

Why class_name TappyPlane while the node is still Plane? Godot already has a math type named Plane. Your class cannot steal that name. Node names are free.

What happens in one physics frame

_physics_process(delta: float) is called on a fixed rhythm. delta is seconds since the last physics tick. velocity.y += config.gravity * delta grows downward speed. move_and_slide() moves the CharacterBody2D from that velocity. Do not multiply velocity by delta again, and do not add to position by hand here.

On one flap, flap() subtracts 300 from current vertical speed, then clamps to -200…200. Y down is positive, so a smaller Y speed means climb. The clamp applies on flap only. Without a flap, gravity keeps increasing fall speed. That matches the reference project.

rotation_degrees is appearance only. Sound plays after the action is valid. Mute the sound and the plane still moves the same way.

Why input lives in _unhandled_input

It receives input the UI has not already used. In Part 3, a “New Game” button click belongs to the button. The plane should not flap from that same click. event.is_echo() drops extra key-repeat events while Space is held.

@onready grabs AudioFlap after this node (and children) are in the tree. $AudioFlap is a path inside this plane, not a project-wide search.

You can press F6 on the plane scene: it falls; keys change speed. Missing spawn point and background is normal. Stop, then build the rock.

5. Rocks: detecting is not blocking

New scene, root Area2D, name Rock, save as src/entities/rock.tscn, attach matching rock.gd. Use lowercase filenames (Godot habit). Paths in code must match disk exactly. Windows editor ignores case; an exported .pck does not. A wrong case gives “editor runs, EXE says Preload file does not exist.”

Add Sprite2D, Texture assets/textures/entities/rocks/rock.png. Add CollisionPolygon2D. Use the polygon tool along the silhouette, close at the start. The lesson uses these seven points (you can type them in the Polygon property):

(9,-119), (15,-119), (26,-16), (39,55),
(51,117), (-52,116), (-15,4)

Area2D reports overlap. It does not shove the plane like a solid wall. For this lesson, turn all Collision Layers off on Rock, check only player on Collision Mask, leave Monitoring on. The rock looks for bodies on the player layer. Do not leave Mask at 0, or overlapping pictures will never report a hit.

Shipped project note (godot_tappy_plane): after debugging, rock.tscn uses collision_layer = 2 (rock) and collision_mask = 0, while the plane (player layer) has mask on rock. Either pairing can fire body_entered if one side actually watches the other. Do not leave both mask and the matching layer empty.

Full rock.gd:

class_name Rock
extends Area2D

signal rock_entered
@export var config: GameConfig

func _physics_process(delta: float) -> void:
	position.x -= config.rock_speed * delta
	if position.x <= config.despawn_x:
		queue_free()

func _on_body_entered(body: Node2D) -> void:
	if body is TappyPlane:
		rock_entered.emit()

Select Rock. Point Config at the same default_game_config.tres. In the Node signals dock, connect the Rock’s own body_entered(body) to _on_body_entered on the root. If the function already exists, pick it. Do not generate a second callback with the same name.

signal rock_entered is a notice with no arguments. emit() sends it. The rock only says “I hit the plane.” It does not hunt for a score label or game-over UI. body is TappyPlane checks that the body is our plane.

queue_free() frees a rock that left the screen at a safe time. This project does not need an object pool. At this size, clear lifetimes matter more.

6. Organize the main scene: world vs spawn

Back in game.tscn, delete the Plane instance you placed by hand under Game. Keep the plane.tscn file. Code will spawn the plane. Two copies would be wrong.

Restructure as below. World and Actors are Node2D. Move Background under Parallax2D. SpawnTimer sits under Game, not under Actors.

Game (Node2D, game.gd)
├── World (Node2D)
│   ├── Parallax2D
│   │   └── Background (Sprite2D)
│   └── Actors (Node2D, empty at start)
├── SpawnTimer (Timer)
└── AudioBgm (AudioStreamPlayer)
  • Parallax2D — Repeat Size (576, 0); Autoscroll (-50, 0)
  • Background — Position (288, 160); Scale (0.72, 0.683333)
  • SpawnTimer — One Shot on; Autostart off
  • AudioBgm — Stream assets/audio/music/Swinging Pants.ogg; Autoplay on; Bus BGM; Volume −15 dB

The Part 1 uniform static scale changes to these numbers to match the scrolling reference. Repeat width matches the scaled image width. Autoscroll is offset per second. See Parallax2D.

Attach game.gd on Game. Replace the whole file. When you read a long script, start at _ready(), then follow the two methods it calls.

extends Node2D

const PLANE_SCENE: PackedScene = preload("res://src/entities/plane.tscn")
const ROCK_SCENE: PackedScene = preload("res://src/entities/rock.tscn")
@export var config: GameConfig
@onready var world: Node2D = $World
@onready var actors: Node2D = $World/Actors
@onready var spawn_timer: Timer = $SpawnTimer
var plane: TappyPlane

var restarting: bool = false

func _ready() -> void:
	spawn_timer.timeout.connect(_on_spawn_timeout)
	_spawn_plane()
	_schedule_rock()

func _process(_delta: float) -> void:
	if is_instance_valid(plane) and not restarting:
		if plane.position.y <= 0.0 or plane.position.y >= get_viewport_rect().size.y:
			_on_hit()

func _on_hit() -> void:
	if restarting:
		return
	restarting = true
	spawn_timer.stop()
	# Hit may arrive from a physics callback. Remove colliders later.
	_restart.call_deferred()

func _restart() -> void:
	_clear_actors()
	_spawn_plane()
	_schedule_rock()
	restarting = false

func _on_spawn_timeout() -> void:
	_spawn_rock()
	_schedule_rock()

func _spawn_plane() -> void:
	plane = PLANE_SCENE.instantiate() as TappyPlane
	plane.config = config
	plane.position = config.plane_start
	actors.add_child(plane)

func _spawn_rock() -> void:
	var rock: Rock = ROCK_SCENE.instantiate() as Rock
	rock.config = config
	rock.rock_entered.connect(_on_hit)
	if randi_range(0, 1) == 0:
		rock.position = Vector2(config.spawn_x,
			randf_range(config.bottom_y.x, config.bottom_y.y))
	else:
		rock.rotation_degrees = 180.0
		rock.position = Vector2(config.spawn_x,
			randf_range(config.top_y.x, config.top_y.y))
	actors.add_child(rock)

func _schedule_rock() -> void:
	spawn_timer.start(randf_range(config.spawn_interval.x, config.spawn_interval.y))

func _clear_actors() -> void:
	for actor: Node in actors.get_children():
		actors.remove_child(actor)
		actor.queue_free()
	plane = null

Save. Drag default_game_config.tres onto Game’s Config slot too. Connect SpawnTimer timeout in code only. Do not also connect it in the editor.

Spawning is four steps

preload() gets the template. instantiate() makes a new node. Set position and config. add_child() puts it in the running scene. as TappyPlane / as Rock tell later lines the real type.

A random bit chooses top or bottom. Top rocks rotate 180°. Bottom rocks stay upright. Each timer end spawns one rock, then picks a new 1–2 second wait. The timer is the only spawn gate. Do not also spawn from _process().

Actors only holds this round’s plane and rocks. Cleanup walks its children. You do not walk the whole tree looking for a global group.

Why this lesson auto-restarts

There is no menu or game-over UI yet. After a hit or leaving the view, the prototype snaps back to spawn so you can test again. restarting blocks two notices in the same frame from restarting twice. call_deferred() waits until physics is not mid-callback before freeing nodes.

This is stage behavior. Part 3 replaces it with a results screen and Retry. It is not a missing final feature.

7. Play the whole loop before you continue

Press F5, not F6 on rock.tscn. First do nothing: watch the plane fall and restart. Then hold height with Space. Confirm rocks enter from the right. Debug → Visible Collision Shapes checks overlap. Turn that off before screenshot polish.

If the plane ignores input, check the flap spelling and that the game window is focused. If Config errors on run, check the Config slot on all three scene roots. If pictures overlap but nothing restarts, check Rock Mask and the body_entered connection.

Close the editor and reopen the project to confirm saves. Part 3 starts from this prototype: a menu first, score per round, then results and a desktop export.
